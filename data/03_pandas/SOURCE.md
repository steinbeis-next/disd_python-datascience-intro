# NASA dataset

The CSV is derived from the actual NASA NeoWs response included beside it. NASA returned close approaches from **7 to 14 October 2025**; the response was retrieved **29 October 2026**. The date range, source endpoint and SHA-256 checksum of the original JSON response are recorded in the adjacent metadata file.

This is a historical teaching snapshot. It is not a current asteroid feed. Two provisional designations occur under different source IDs, so 26 rows do not establish 26 unique physical objects. See the notebook before interpreting group comparisons.
