# Air-quality exercise data

`air_quality_sample.csv` is **made-up data for practising pandas**. It is not OpenAQ data, does not represent real Berlin or Delhi measurements, and must not be used to make a health, policy or city comparison claim.

The rows mimic the shape of a monitoring dataset: date, city, station, pollutant, unit and value. Use the file to practise table operations offline. A separate optional final exercise asks how you would replace it with verified OpenAQ measurements.
